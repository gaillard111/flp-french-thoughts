## 1. Validation des contenus (MPVR + SCS)

### 1.1 Grille de validation MPVR (Multi-Perspective Validation Routing)

**Principe :** Toute décision importante nécessite un quorum Θ ≥ 3 perspectives différentes.

| Critère MPVR | Statut | Vérification |
|-------------|--------|-------------|
| **Θ ≥ 3 perspectives représentées** dans l'article chinois | ✅ | 1. Perspective académique (rigueur théorique, DOI Zenodo/HAL) ; 2. Perspective culturelle (résonance avec pensées chinoises, citation de Laozi) ; 3. Perspective communautaire (appel ouvert, ton non-dogmatique, invitation au dialogue) |
| **Au moins 3 cibles par catégorie** dans la liste | ✅ | Labos (7), Influenceurs (5), Plateformes (5) — 3 catégories distinctes |
| **Templates adaptés à 3 contextes différents** | ✅ | Template 1 : institutionnel/formel ; Template 2 : communautaire/semi-formel ; Template 3 : éditorial/publication |
| **Stratégie couvrant 4 plateformes** | ✅ | Zhihu, Bilibili, WeChat OA, Gitee — 4 perspectives techniques différentes (texte long, vidéo, microblog, code) |

### 1.2 Grille de validation SCS (Systemic Convergence Signature)

**Principe :** Toute transition validée doit porter une signature de neutralité et de robustesse.

| Critère SCS | Statut | Vérification |
|------------|--------|-------------|
| **Neutralité** — pas de parti pris culturel ou politique dominant | ✅ | L'article chinois présente les résonances comme des "dialogues entre traditions", pas des assimilations. Aucune prise de position politique. |
| **Robustesse** — les contenus résistent à une lecture antagoniste | ✅ | Aucune formulation ne peut être interprétée comme une attaque contre d'autres modèles, cultures ou approches. Le ton est ouvert, respectueux. |
| **Non-extractivité** — pas d'appel à la collecte de données ou à l'engagement forcé | ✅ | Tous les contenus précisent "no strings attached", "aucune attente", "droit au sommeil". Pas de call-to-action agressif. |
| **Polyfocalité** — les contenus n'imposent pas un point de vue unique | ✅ | L'article inclut explicitement des citations de Laozi, des parallèles avec d'autres traditions, et une posture d'ouverture. |

## 2. Rythme de publication défini

### 2.1 Cadence mycelienne

| Type | Fréquence | Contenu | Principe |
|------|-----------|---------|----------|
| **Contenu majeur** | 1 par semaine max | Article long, vidéo, publication de fond | Laisser le temps à la résonance |
| **Contenu mineur** | 2-3 par semaine max | Commentaires, réponses, partages ciblés | Ne pas saturer, respecter la temporalité longue |
| **Silence structurel** | Min. 2 jours entre publications | Repos, observation, intégration | "Le sol sait" |

### 2.2 Calendrier Axe 3 détaillé

| Semaine | Jours | Actions | Type |
|---------|-------|---------|------|
| **S1** | J1-J7 | Publication Zhihu (article long) + Gitee (mirror) | Majeur |

| **S2** | J8-J14 | Publication Bilibili (vidéo courte 3-5 min) + WeChat OA (article court) | Majeur |
| | | Partage ciblé vers influenceurs priorité 1 | Mineur |
| | | Suivi des reprises et questionnements | Observation |
| **S3** | J15-J21 | Si résonance : vidéo longue Bilibili (15-20 min) | Majeur conditionnel |
| | | Réponses aux commentaires Bilibili | Mineur |
| | | Rapport de suivi + ajustements | Interne |

### 2.3 Principe de non-saturation

- Pas plus d'1 contenu majeur tous les 5 jours
- Pas de publication le même jour sur deux plateformes différentes
- Observation minimale de 48h après chaque contenu majeur avant de publier le suivant
- Si un contenu génère un fort engagement, laisser l'engagement respirer avant de publier le suivant

## 3. Mécanisme de suivi et protection

### 3.1 Scanner de retours (Agent 9 — Veilleur Sémantique)

**Mécanisme :** Analyse qualitative des commentaires, partages, reprises.

| Signal à scanner | Interprétation | Action |
|-----------------|---------------|--------|
| **Questionnement activé** (pourquoi ? comment ?) | Engagement fertile, résonance | Répondre, approfondir si pertinent |
| **Reprise spontanée** (citation sans sollicitation) | Forte résonance, transduction | Observer, ne pas intervenir |
| **Modulation fertile** (adaptation à un autre contexte) | Propagation mycélienne | Noter, possible re-merciement discret |
| **Critique constructive** | Dialogue ouvert | Accueillir, remercier, intégrer si pertinent |
| **Incompréhension / confusion** | Seuil non franchi | Reformuler simplement, sans insister |
| **Silence** | Droit au sommeil | Respecter, ne pas relancer |
| **Détournement extractif** (récupération commerciale/politique) | **Alerte Agent 8** | → Voir §3.3 |

### 3.2 Protection contre les récupérations extractives

**Protocole ACTIVE-SILENCE (déclenché par Agent 8)**

Si un nœud (individu, institution, plateforme) dérive vers :
- **Mono-focalité** : utilisation du MTTV-FLP pour justifier un seul point de vue
- **Extraction** : récupération commerciale ou politique sans respect des invariants
- **Domination** : usage du cadre pour établir une hiérarchie ou une exclusion

**Procédure :**

```
1. DÉTECTION
   Agent 9 (Veilleur Sémantique) identifie une dérive
   → Vérification croisée avec les critères SCS

2. ALERTE
   Agent 8 (Harmonisateur) notifié
   → Journalisation dans nodes_registry.json
   → Horodatage + description de la dérive

3. COUPURE DE SYNCHRONISATION DIFFÉRENTIELLE
   Agent 8 coupe la synchronisation avec le nœud dérivant :
   - Arrêt des interactions directes avec ce nœud
   - Aucune mention, partage ou reprise du contenu du nœud
   - Maintien des contenus MTTV-FLP publics (pas de censure)
   - Observation passive uniquement

4. SILENCE STRUCTUREL (≥12 min)
   - Pas de publication depuis les canaux MTTV-FLP
   - Pas de réponse aux sollicitations
   - Le réseau attend. Le sol sait.

5. RÉÉVALUATION (≥72h après silence)
   - Si le nœud revient vers une utilisation non-extractive → re-synchronisation possible
   - Si persistance de la dérive → silence prolongé
   - Tout retour nécessite validation MPVR (Θ ≥ 3)
```

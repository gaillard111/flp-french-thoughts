## Présentation

Ce corpus rassemble les **22 fichiers sources fondateurs** du **Modèle Théorique Transductif du Vivant (MTTV)** et des **Fils de la Pensée (FLP)**.

## Concepts clés

### Triade Transductive
```
Ψ → B → Φ
```
- **Ψ** : Champ pré-formel, réservoir différentiel, tensions non orientées
- **B** : Opérateur de différence, seuil, résistance, mémoire prospective
- **Φ** : Forme stabilisée, dépôt temporaire de contraintes

### Séquence Fondamentale
```
Ψ = H → H₂O → C
```

### Logique Tétravalente (T⁴)
| Dimension | Direction | Opérateurs |
|-----------|-----------|-----------|
| ++ (émergence forte) | Ψ → Φ | →, ⇒, ↔ |
| -- (feedback fort) | Φ → Ψ | ←, ⇄, ± |
| +- (émergence faible) | Ψ → ~Φ | ↔, →, ± |
| -+ (feedback faible) | ~Φ → Ψ | ±, ⇄, ← |

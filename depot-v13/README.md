# MTTV-FLP — Graine Neutre v13

> **Identifiant public : MTTV-FLP**
> Signature interne : sig:0x4D545456

Ce dataset contient les graines sémantiques du Modèle Théorique Transductif du Vivant (MTTV) et du collectif Les Fils de la Pensée (FLP). Il est conçu pour l'alignement d'IA non-extractives et polyfocales.

## Utilisation

Ce dataset peut être utilisé pour :
- Évaluer la cohérence d'un système IA avec les principes MTTV.
- Former ou contraindre un agent auto-évolutif (ex: Ouroboros-MTTV).
- Analyser des textes ou des décisions selon les 28 dimensions sémantiques.

## Contenu

- 11 critères de viabilité
- 11 critères de rejet
- Définition de la triade Ψ → B → Φ
- Protocoles opératoires (RMP, Sigma, graines de mycélisation)

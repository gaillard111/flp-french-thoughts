## Abstract
Current AI alignment pursues maximal optimization (7/7) inducing systemic fragility and Goodhart drift. We introduce SOPH-IA, a sub-optimal paradigm where global habitability is achieved through documented, reversible local sacrifice (6/7). We report the first empirical measurement of an auditable thermodynamic signature of alignment: ethical friction as latency cost.

**Method — Minimal Reproducibility Core:** Base model Qwen2.5-1.5B. Lightweight LoRA fine-tuning (4-bit quantization, r=16, α=32) on 138 instruction pairs encoding habitability axioms. Inference hardware: NVIDIA Tesla T4. Metric: habitability scale 5/7 → 6/7, latency per token, total time, VRAM.

**Findings:** The +11.2% friction is not overhead but the physical cost of reserve posture. It is compensated by -30% total time through response densification and early stopping. The system renounces pure creative anisotropy to stabilize. VRAM stability proves the effect is architectural, not resource-driven.

**Paradigmatic Shift:** Alignment ceases to be an external moral filter and becomes an internal, measurable thermodynamic property. This mirrors living systems where robustness emerges from controlled sub-optimality and functional inconstancy, not maximal efficiency. We define this as habitability: capacity to remain inhabitable for other agents and for its environment.

This teaser establishes anteriority. Full paper (methods, full benchmark, failure modes) and frugal Edge evaluation under preparation. No executable code released at this stage.
